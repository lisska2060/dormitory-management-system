# Dormitory Management System
Навчальний проєкт з дисципліни "Інженерія програмного забезпечення".
## Опис системи
Система управління гуртожитком призначена для:
- поселення студентів;
- виселення мешканців;
- обліку кімнат;
- контролю оплат;
- формування звітів.
## Технології
- Python
- Django
- PostgreSQL
- GitHub
## Етапи виконання проєкту
1. Створено репозиторій.
2. Додано структуру проєкту.
3. Описано вимоги.
4. Побудовано UML-діаграми.
5. Спроєктовано архітектуру системи.
6. Створено pull request.
