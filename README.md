# Dormitory Management System

Навчальний проєкт з дисципліни "Інженерія програмного забезпечення".

## Опис системи

Система призначена для автоматизації роботи гуртожитку:
- поселення студентів;
- виселення мешканців;
- облік кімнат;
- контроль оплат;
- формування звітів.

## Технології
- Python
- Django
- PostgreSQL
- GitHub

5. Спроєктовано архітектуру системи.
